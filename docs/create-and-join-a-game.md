# Create and join an ORGANISM game

ORGANISM now separates game setup from the waiting room. Creating a lobby does not start play, and joining the last open seat does not start play.

## Create a game

1. Sign in and choose **Create a game**.
2. Give the game a name.
3. Choose the number of players and field size.
4. Choose who may join:
   - **Open game** appears in the public game list and may be joined by any signed-in player.
   - **Private game** stays out of public discovery. Share its invite link and lobby password directly with friends.
5. Optionally add a description.
6. Choose **Launch lobby**.

Launching seats you in seat 1 and opens the remaining seats. It does not start the game.

## Invite and join players

Open lobbies can be joined from the game list or from their invite link. A player chooses an open seat and joins under their signed-in account name.

For a private lobby:

1. Open the invite link from the owner.
2. Enter the lobby password.
3. Choose an open seat.

Lobby passwords are checked by the server and are not stored as readable text. Repeated incorrect attempts are temporarily limited.

## Use the lobby

The lobby keeps the information needed to coordinate the table in one place:

- Copy the invite link.
- See occupied and open seats.
- Talk in lobby chat. This conversation remains available after the game starts.
- Ready or unready your own human seat.
- See the exact reason the game cannot start yet.

Bots are always ready.

## Owner controls

The player who created the lobby is its owner. Before play, the owner can:

- edit the field size and description;
- kick another player;
- share the invite;
- start the game after every seat is occupied and every human player is ready.

Changing a gameplay setting clears readiness so everyone can review the updated table. The lobby name and owner seat remain stable.

## Start the game

Each human player chooses **Ready up**. When all seats are occupied and all humans are ready, the owner’s **Start game** button becomes available. Only the owner can start.

If someone is removed or a setting changes, the lobby returns to a waiting state. Joining, filling the final seat, or posting chat never starts the game automatically.

## Troubleshooting

- **Start game is disabled:** Read the message beside it. It names the missing seat or players who have not readied up.
- **A private game is not in the game list:** That is expected. Use its invite link.
- **A private password does not work:** Ask the owner to confirm the password. After repeated failures, wait a minute before retrying.
- **You cannot take another seat:** One signed-in account can occupy only one seat in a lobby.
- **You were kicked:** Your membership and ability to post lobby chat are removed immediately. Ask the owner for a new invitation if this was accidental.
