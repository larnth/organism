# In-game discussion

The **Details** drawer includes a live discussion area so seated players can coordinate without leaving the board.

## Sending a message

1. Open **Details** during a game.
2. Type in **Write to the table…**.
3. Press Enter or select **Send**.

The composer shows **Sending…** until the server confirms the message. After confirmation, the message appears once in the conversation and the composer changes to **Sent**. If the connection is unavailable, the server rejects the post, or confirmation does not arrive within eight seconds, the draft remains in the input so it can be retried rather than disappearing.

Messages show the author and local send time. Your messages align separately from the other players’ messages. The most recent 15 messages are shown. Observers can read the discussion but cannot post.

Lobby discussion and in-game discussion use the same delivery behavior, and lobby messages carry into the started game.
